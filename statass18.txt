## T-test in Excel: France vs. Germany average order value

You can use a two-sample t-test to determine whether the average order value differs significantly between customers in France and Germany, using your `OnlineRetail.csv` dataset.

### 1. Prepare the data

First, calculate each invoice's total order value by summing `Quantity × UnitPrice` for all items on that invoice. Then assign each invoice to its country.

Create a summary table with one row per invoice, containing:

- `InvoiceNo`
- `Country`
- `OrderValue`

Filter the summary into two groups: France and Germany.

### 2. Run the t-test in Excel

If your France order values are in `A2:A100` and Germany order values are in `B2:B100`, enter:

excel

```
=T.TEST(A2:A100,B2:B100,2,3)
```

- `2` specifies a two-tailed test.
- `3` specifies a two-sample test assuming unequal variances (Welch's t-test).

Replace the ranges with the actual cells containing each country's invoice totals, excluding blank cells.

### 3. Interpret the result

Use a significance level of $\alpha=0.05$.

- If the p-value is less than 0.05, reject the null hypothesis: there is a statistically significant difference in average order value between France and Germany.
- If the p-value is 0.05 or greater, fail to reject the null hypothesis: there is insufficient evidence of a statistically significant difference.
