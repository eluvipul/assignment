2. Key Components in Power BI Desktop
Report View: The main canvas where you design dashboards with visuals.

Data View: Shows the raw tables and columns imported into Power BI.

Model View: Displays relationships between tables in a diagram format.

Fields Pane: Lists all available tables and fields you can drag into visuals.

Visualizations Pane: Contains chart types and formatting options to build visuals.

Filters Pane: Lets you apply filters at visual, page, or report level.

4.Data Connectivity

Excel: Primarily works with static datasets or manual imports.

Power BI: Connects directly to multiple live data sources (SQL, cloud services, APIs) with automatic refresh options.

Interactivity

Excel: Offers limited interactivity through slicers, filters, and pivot tables.

Power BI: Provides dynamic drill-downs, cross-filtering between visuals, and interactive dashboards that respond instantly to user actions.

Sharing & Collaboration

Excel: Shared as files via email, OneDrive, or SharePoint.

Power BI: Dashboards can be published to the Power BI Service, enabling real-time collaboration, role-based access, and cloud-based updates.
