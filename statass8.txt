import random

# Probability of successful login
p = 0.85

# Simulate 20 Bernoulli trials
results = [
    1 if random.random() < p else 0
    for _ in range(20)
]

print("Login results (1 = Success, 0 = Failure):")
print(results)

print("Successful logins:", results.count(1))
print("Failed logins:", results.count(0))

from scipy.stats import binom

def upi_payment_probability(n, k, p):
    # Probability of exactly k successful payments
    probability = binom.pmf(k, n, p)
    return probability

# Parameters
n = 5      # Total payment attempts
k = 3      # Exactly 3 successful payments
p = 0.9    # Probability of success per payment

result = upi_payment_probability(n, k, p)

print("Probability of exactly 3 successful payments:", result)
print(f"Probability in percentage: {result * 100:.2f}%")

AI-generated real-world use case: IRCTC
Scenario: IRCTC wants to analyze how many ticket booking requests it receives per minute during peak booking hours. Suppose the system receives an average of 50 booking requests per minute. IRCTC can use the Poisson distribution to estimate the probability of receiving 40, 50, or 60 requests in a particular minute. This helps the company plan server capacity, manage traffic spikes, and reduce booking failures.

Why does the Poisson distribution fit?
The Poisson distribution is suitable because it models the number of events occurring within a fixed time interval when events happen at a relatively stable average rate. Here, the events are ticket booking requests per minute, which helps IRCTC anticipate traffic and allocate server resources efficiently.
